# kolsscan.github.io

Сайт KoL'SScan на GitHub Pages: главная (`index.html`) и политика конфиденциальности (`privacy.html`, ссылка для Chrome Web Store — https://kolsscan.github.io/privacy).

Код расширения — в приватном репо `h100envy/kols-scan`. `privacy.html` собирается из его `PRIVACY.md`: при изменении политики обновить оба.

Страница в Store (с 2026-10-11, v1.0.1): https://chromewebstore.google.com/detail/kolsscan-%E2%80%94-kol-call-track/dpggfhnpoemnljlchhdnmjdbbobhngdo — кнопка «Add to Chrome» в `index.html` и пункт FAQ в `support.html`. Ролик на главной — `video/` (рендер `dev/promo/promo.html?v=release&br=2` из репо расширения, ~5 МБ).
